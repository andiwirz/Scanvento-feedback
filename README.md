# Scanvento – Feedback

**Deutsch** · [English](#english)

Hier meldest du Fehler, wünschst dir Funktionen oder stellst Fragen zu [Scanvento](https://scanvento.com), dem Unified Asset Hub.

- **Fehler melden:** [Neues Issue → «Fehler»](../../issues/new?template=bug_report.yml)
- **Funktion wünschen:** [Neues Issue → «Wunsch»](../../issues/new?template=feature_request.yml)
- **Frage stellen:** [Neues Issue → «Frage»](../../issues/new?template=question.yml)
- **Sicherheitslücke?** Bitte **nicht** hier melden, sondern vertraulich an **contact@scanvento.com** (siehe [SECURITY.md](SECURITY.md)).

Bevor du ein neues Issue erstellst, schau bitte, ob es schon gemeldet wurde ([offene Issues](../../issues)).
Die Dokumentation findest du unter <https://scanvento.com/docs>.

> **Early Access:** Scanvento befindet sich in einer frühen Entwicklungsphase. Noch nicht alle Funktionen sind vollständig ausgetestet.

**Tipp:** In der App unter *Hilfe → Problem melden* werden Version, Seite und Fehler-ID automatisch ergänzt. Administratoren können dort ein Support-Paket herunterladen und hier anhängen – prüfe es vorher auf vertrauliche Angaben.

## English

This is where you report bugs, request features or ask questions about [Scanvento](https://scanvento.com), the Unified Asset Hub.

- **Report a bug:** [New issue → "Bug"](../../issues/new?template=bug_report.yml)
- **Request a feature:** [New issue → "Feature request"](../../issues/new?template=feature_request.yml)
- **Ask a question:** [New issue → "Question"](../../issues/new?template=question.yml)
- **Security vulnerability?** Please do **not** report it here; send it confidentially to **contact@scanvento.com** (see [SECURITY.md](SECURITY.md)).

Before opening a new issue, please check whether it has been reported already ([open issues](../../issues)).
Documentation: <https://scanvento.com/docs>.

> **Early access:** Scanvento is at an early stage of development. Not all features have been fully tested yet.

**Tip:** In the app, *Help → Report a problem* adds the version, page and error id automatically. Administrators can download a support bundle there and attach it here – check it for confidential details first.
