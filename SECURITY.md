# Sicherheitslücken melden / Reporting security vulnerabilities

**Bitte melde Sicherheitslücken nicht öffentlich als Issue.** Schreibe stattdessen an **contact@scanvento.com** mit dem Betreff «Security».

Hilfreich sind:
- betroffene Version von Scanvento (Administration → System) und Betriebsart (Docker, Linux, Windows, Kubernetes, TrueNAS)
- Beschreibung der Lücke und mögliche Auswirkungen
- Schritte zum Nachstellen bzw. ein Proof of Concept
- ob und wie die Lücke bereits ausgenutzt wird

Wir bestätigen den Eingang so schnell wie möglich, halten dich über den Stand auf dem Laufenden und nennen dich auf Wunsch in den Versionshinweisen.

---

**Please do not report security vulnerabilities as public issues.** Write to **contact@scanvento.com** with the subject "Security" instead.

Helpful details:
- affected Scanvento version (Administration → System) and deployment (Docker, Linux, Windows, Kubernetes, TrueNAS)
- description of the vulnerability and its possible impact
- steps to reproduce or a proof of concept
- whether and how it is being exploited

We acknowledge your report as soon as possible, keep you informed about its status and credit you in the release notes if you wish.
